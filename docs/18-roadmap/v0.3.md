# Roadmap: v0.3 — Plugins, Dashboard & Multi-Tenancy

**Document ID:** RM-003  
**File Path:** `docs/18-roadmap/v0.3.md`  
**Version:** 1.0.0  
**Status:** Planned  
**Owner:** Product Team  
**Last Updated:** 2026-06-27

---

# 1. Theme

**Ecosystem and experience.** Open the platform to extensions and give users a full
visual experience, on a multi-tenant foundation.

---

# 2. Goals

- **Plugin system**: Plugin Engine, WASM loading, signing/provenance, grants
  ([section 08](../08-plugin-sdk/index.md)).
- **Marketplace** (v1): discovery, install, governance
  ([marketplace](../08-plugin-sdk/marketplace.md)).
- **Dashboard**: workflow builder, agent studio, memory explorer, monitoring,
  settings ([section 10](../10-dashboard/index.md)).
- **Multi-tenancy**: orgs/projects, quotas, RBAC/ABAC end to end
  ([projects](../09-api/projects.md), [security](../13-security/index.md)).
- **Platform API** stabilized at `/v1` ([section 09](../09-api/index.md)).

---

# 3. In Scope

| Area | Deliverable |
|------|-------------|
| Plugins | Author → sign → publish → install → grant flow |
| Dashboard | All core surfaces, real-time |
| Tenancy | Quotas, fair scheduling, isolation hardening |
| API | Stable `/v1`, webhooks |
| Security | Full audit, secret vault, supply-chain checks |

---

# 4. Out of Scope (deferred)

- GA hardening, compliance certifications → [v1.0](v1.0.md)
- Multi-region / edge → [v1.0](v1.0.md) / [future](future.md)

---

# 5. Exit Criteria

- A third-party [plugin example](../16-examples/vpn-agent.md) is built, published,
  installed, granted, and used.
- Teams operate self-serve via the dashboard with enforced quotas.
- Security testing ([section 15](../15-testing/security-testing.md)) passes,
  including zero cross-tenant leakage.
