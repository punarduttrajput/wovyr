# Roadmap: v0.2 — Memory, Tools & Gateway Hardened

**Document ID:** RM-002  
**File Path:** `docs/18-roadmap/v0.2.md`  
**Version:** 1.0.0  
**Status:** Planned  
**Owner:** Product Team  
**Last Updated:** 2026-06-27

---

# 1. Theme

**Depth and durability.** Make the core engines production-shaped: real memory,
durable workflows, stronger tool isolation, and a resilient gateway.

---

# 2. Goals

- **Memory Engine**: PostgreSQL + Qdrant tiers, hybrid
  [retrieval](../06-memory-engine/retrieval.md), ranking, compression.
- **Workflow Engine**: durable executions with
  [checkpointing](../03-workflow-engine/checkpointing-specification.md),
  [retry](../03-workflow-engine/retry-engine.md), and
  [compensation](../03-workflow-engine/compensation-engine.md).
- **Tool Runtime**: container + gVisor/microVM sandboxes
  ([sandbox runtime](../07-tool-runtime/sandbox-runtime.md)) and worker pools.
- **LLM Gateway**: failover, circuit breaking, caching, token/cost accounting.
- **Observability**: metrics, tracing, logging baseline
  ([section 14](../14-observability/index.md)).

---

# 3. In Scope

| Area | Deliverable |
|------|-------------|
| Memory | Namespaces, hybrid search, knowledge graph (v1) |
| Workflow | DAG + state machine + durable resume |
| Tools | Strong sandboxes, fair scheduling, autoscaling |
| Gateway | Resilience + caching + cost events |
| Ops | Dashboards, alerts, SLOs |

---

# 4. Out of Scope (deferred)

- Plugin marketplace + third-party plugins → [v0.3](v0.3.md)
- Full dashboard UX → [v0.3](v0.3.md)
- Multi-region → [v1.0](v1.0.md)

---

# 5. Exit Criteria

- [RAG agent](../16-examples/rag-agent.md) and a durable
  [support workflow](../16-examples/customer-support.md) run reliably.
- Resilience validated by [chaos tests](../15-testing/chaos-testing.md).
- Performance meets baseline [NFRs](../15-testing/performance-tests.md).
