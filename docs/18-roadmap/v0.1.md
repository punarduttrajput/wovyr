# Roadmap: v0.1 — Foundations

**Document ID:** RM-001  
**File Path:** `docs/18-roadmap/v0.1.md`  
**Version:** 1.1.0  
**Status:** Implemented (foundation slice complete)  
**Owner:** Product Team  
**Last Updated:** 2026-06-27

---

# 1. Theme

**Foundations.** Establish the architecture, documentation, and the first runnable
slice: a single agent executing with tools and an LLM, on a minimal runtime.

---

# 2. Goals

- Complete the architecture and component specifications (this docs set).
- Stand up the monorepo and build/CI ([ADR-0001](../17-adr/ADR-0001-project-structure.md)).
- Minimal **Agent Runtime** executing a [hello agent](../16-examples/hello-agent.md).
- Minimal **LLM Gateway** with one or two providers
  ([Provider SDK](../04-agent-framework/provider-sdk.md)).
- Minimal **Tool Runtime** with native sandbox + a few built-in tools.
- Single-binary [Docker](../12-deployment/docker.md) dev image.
- `wovyr` [CLI](../11-cli/index.md) basics: `login`, `agents run`, `--local`.

---

# 3. In Scope

| Area | Deliverable |
|------|-------------|
| Docs | Sections 00–17 drafted |
| Runtime | Agent run loop (plan → tool → model → respond) |
| Gateway | Chat + embeddings, basic routing |
| Tools | Native sandbox, `fs`/`http`/`shell` |
| CLI | Auth + run + local mode |
| Build | Workspace, CI (unit + integration) |

---

# 4. Out of Scope (deferred)

- Distributed workflow durability at scale → [v0.2](v0.2.md)
- Plugins, marketplace → [v0.3](v0.3.md)
- microVM/gVisor sandboxes → [v0.2](v0.2.md)
- Dashboard → [v0.3](v0.3.md)

---

# 5. Exit Criteria

- [x] A documented agent runs end to end locally (`wovyr agents run --local`) and
  against a single-node server (`wovyr dev` + `wovyr agents run --server`).
- [x] Unit + integration CI green ([testing](../15-testing/index.md)) — workspace
  builds clean under `clippy -D warnings` with 34 passing tests.
- [x] Architecture stable enough to build v0.2 on.

> Implementation note: the v0.1 code lives in a Cargo workspace (`crates/`,
> `apps/`). The server's run endpoint accepts an inline agent manifest
> (`POST /api/v1/agents:run`) pending the agent store; remote streaming (SSE),
> stronger sandbox isolation, and persistence are deferred to
> [v0.2](v0.2.md)/[v0.3](v0.3.md).
