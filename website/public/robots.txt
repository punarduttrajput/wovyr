# Everything here is public Apache-2.0 documentation for an open-source project,
# so the policy is simply: crawl all of it. Nothing on this origin is gated,
# personalised, or user-generated, and there is no login — so there is no
# section that needs excluding, and no crawl-rate concern for a static site.
#
# The AI/answer-engine crawlers below are listed EXPLICITLY rather than left to
# the wildcard. That is deliberate: being cited accurately in an answer engine
# is the point for a project whose documentation is its interface, and several
# of these agents treat an absent, specific rule differently from an explicit
# allow. Listing them also documents the intent, so nobody later "tightens"
# robots.txt without realising it opts the docs out of AI citation.
#
# Machine-readable summaries for LLM consumption live at:
#   /llms.txt        index — every page with a one-line description
#   /llms-full.txt   the complete documentation corpus in a single file
